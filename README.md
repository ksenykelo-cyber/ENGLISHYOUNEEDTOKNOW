# Мои слова — тренажёр английского

Сайт, на который можно выгружать английские слова с переводом, а он превращает их
в карточки для тренировки. Слова, которые ты плохо помнишь, показываются чаще;
хорошо выученные — реже (по системе Лейтнера, 5 уровней).

Разделы:

- **Тренировка** (`/`) — карточки на сегодня. Тапаешь по карточке, чтобы увидеть
  перевод, затем отмечаешь «Помню» или «Не помню».
- **Добавить** (`/add`) — добавить слово вручную или вставить список сразу
  (`word - перевод`, по одному слову в строке; после `|` можно добавить пример).
- **Список** (`/words`) — все слова, поиск, редактирование, удаление.

## Локальный запуск

```bash
npm install
npm run dev
```

Открой [http://localhost:3000](http://localhost:3000). Без дополнительной настройки
слова сохраняются в файл `data/words.json` — этого достаточно для разработки.

## Деплой на Vercel (чтобы сайт был доступен онлайн и с телефона)

1. Зайди на [vercel.com](https://vercel.com), войди через GitHub.
2. **Add New → Project**, выбери этот репозиторий (`ENGLISHYOUNEEDTOKNOW`), нажми Deploy.
3. Подключи хранилище, чтобы слова сохранялись между заходами (без этого шага сайт
   откроется, но добавленные слова не будут сохраняться на серверe):
   - В проекте на Vercel открой вкладку **Storage → Create Database → Redis**
     (провайдер Upstash, есть бесплатный тариф).
   - После создания подключи её к проекту (Connect Project) — Vercel сам добавит
     нужные переменные окружения (`KV_REST_API_URL` / `KV_REST_API_TOKEN` или
     `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN` — приложение понимает оба варианта).
   - Сделай **Redeploy** проекта, чтобы переменные подхватились.
4. Готово — открывай ссылку сайта с телефона, добавляй слова с компьютера или
   с телефона, всё видно в обоих местах.

Пока Redis не подключён, каждый деплой на Vercel будет работать с пустым
хранилищем (файловая система на серверless-функциях не сохраняется между
запросами) — поэтому шаг 3 обязателен для реального использования.
